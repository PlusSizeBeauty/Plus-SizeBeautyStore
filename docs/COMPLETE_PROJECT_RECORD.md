# Affiliate store project record

This project is a static affiliate storefront for PlusSizeBeauty. The goal is to present categories, product recommendations, and brand storytelling without acting as a retailer or taking orders.

## Scope

- Site type: static HTML/CSS/JS affiliate storefront
- Uses: GitHub Pages or similar static hosting
- Product handling: manually managed affiliate product data in `data/affiliate-products-template.csv`
- Business model: affiliate links only
- Payment system: not included
- Checkout/cart: not included

## Simple structure

- `index.html` — home page and catalog overview
- `about.html` — brand story and business positioning
- `disclosure.html` — required affiliate disclosure page
- `script.js` — renders product cards and filters categories
- `styles.css` — visual design and layout
- `data/affiliate-products-template.csv` — record of recommended items, link status, and review notes

## Required before public launch

- Verified affiliate links from the actual retailer or affiliate network
- Approved product images or image rights
- Confirmed affiliate disclosure
- Site preview in a browser
- GitHub Pages or static host publish
- Final review of all outgoing links and content

## Status

The repo now contains a working static affiliate storefront concept that can be reviewed locally. It is ready for content review, but it is not yet final because sample/placeholder product links and program terms must be replaced with real approved data before public publishing.
